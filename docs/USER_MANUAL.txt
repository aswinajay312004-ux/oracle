NEW ORDER
  1. Upload: Excel ah drop pannunga.
  2. Map to Oracle:

       cell endha table ku poghudhu).
     - Maatha: Excel la cells select pannunga (drag, Shift+click, Ctrl+click,
       column letter / row number click, illa "E12:P20" maadhiri type), apram
       Oracle column la "Use selection".
     - Pala columns ore nerathula (udharanam 20 size columns): Excel la
       andha columns ah select pannunga, valadhu pakkam Oracle columns ah
       tick pannunga, "Map in order" - mudhal Excel column mudhal tick ku,
       rendaavadhu rendaavadhu ku...

       quantities block, ORDSTYLE colour (COMBO) ku colour cells.
     - ORDACC / ORDFAB / ORDYARN: select panna ovvoru Excel row um oru Oracle
       row aagum.

PART 7. NEW ORDER - EXCEL IRUNDHU ORACLE KU (MAIN WORK)
--------------------------------------------------------------------------------

Mela 4 steps theriyum: 1 Upload -> 2 Review -> 3 Check & approve -> 4 Saved.

STEP 1 - UPLOAD
  "Drag & drop the order file" box la file ah podunga, illa "choose a file".
  Accept aagura files:
    .xlsx .xlsm .xltx .xltm .xls .xlsb .ods
    Excel XML (2003) and HTML exports (.xml .htm .html, ERP la irundhu
    "Excel" nu export aagura files)
    .csv .tsv .txt (tab text), .json
  Size: 12 MB varaikum. File laptop laye irukkum.
  "Recent files" la munnadi upload pannadhu irukkum, thirumba open pannalaam.

  Upload aanadhum "Reading your file..." screen varum. Enna kandupidichadhu nu
  kaattum (header, sizes, packs, fabric kg, trims). "Open the order entry ->"
  click pannunga.

STEP 2 - REVIEW (Axpert madhiri screen)
  Order header: buyer, style, description, PO / contract number, order
  reference (OC number), order date, ship date, season, merchandiser,
  exporter, sample type, quantity unit...
  Style & size quantities: colour x size table.
  Fabric planning: portion wise fabric, kg calculation
    (kg = pieces x g/pc / 1000 x rejection).
  Trims & accessories: file la irukura trim tables apdiye.

  Ovvoru value um Excel la endha cell la irundhu vandhuchu nu theriyum.

  RED / ORANGE OUTLINE:
    Edhavadhu missing or thappu na andha field ae red la outline aagum, keela
    oru line la karanam irukkum. "Show me the next one >" click panna adutha
    prachanai ku pogum. Orange = padichu paakkanum (warning), red = fix
    pannanum (error).

  Usually neenga fill panna vendiyadhu (file la illana):
    - Order reference (OC No) - kaaliyaa vittaa save pannumbodhu automatic aa
      adutha number varum (e.g. PK/26-27/S/1320 irundhaa PK/26-27/S/1321).
      Series config/company.json la "order_number" la irukku. Type panna,
      adhu unique aa irukkanum.
    - Order confirmation date, ship date (ship date >= order date).
    - Quantities to save: "Sample section", "Buyer order" (demo ku), illa
      "Type them" (neengale type pannradhu).
    - Quantity unit: pieces (PCS) illa packs (PACK); pack na "Pieces in one
      pack" kudukkanum. Packs pieces aa convert aagi save aagum.

  UNDO / REDO: mela buttons, illa Ctrl + Z / Ctrl + Y. Type panna ellame onnu
  onna thirumba edukkalaam (approve pannuradhuku munnadi varaikum).

  "Read this file differently": file ah thappaa purinjikitta, column
  mapping ah neengale kaattalaam (PART 7A).
  "Ask about this file": indha file pathi kelvi kekkalaam.
  "+ Add another order manually": file illama order type pannalaam.
  New size column add panna "+ size" la size name type pannunga.

  Mudinjadhum "Check & continue ->" click pannunga. Oracle la masters, existing
  orders, units, totals, column size, relationships ellame check aagum.
  Prachanai irundha thirumba andha field la red aa kaattum.

STEP 3 - CHECK & APPROVE
  "Open the approval view ->" click panna:
  - Flowchart: endha endha Oracle tables la ezhudhum (ORDMAS, ORDSTYLE,
    ORDSIZE, masters...). Table ah click panna adhula pogura rows table aa
    keela theriyum, ovvoru value um endha Excel cell la irundhu nu.
  - "Please read before approving": warnings. Padichutu approve pannunga.
  - Approver / admin ku "Accept and save to Oracle ->" button varum.
    Ellaa rows um ORE transaction la save aagum: ellame save, illa onnum
    illa. Paadhi save aagi nikkaadhu.

PUDHU EASY FLOW (2026-10-19):
  Excel upload pannunga. Format theriyum na app thaane ellam fill panni
  Oracle oda check pannum, apram "Check and accept" popup varum:
    - Order (OC No - adutha number, buyer, style, PO, dates, colour x size)
    - "Where each value goes in Oracle": ovvoru table la enna values
      (Order header, Colour lines, Sizes, pudhu masters)
    - "Before you approve": save aagaadha values, "Check" points
  Ellam sari na "I've reviewed these items" tick -> Accept and save.
  Maathanum na "Edit" -> entry screen la maathi "Check & continue".
  File la order confirmation date illaatti inniku date ("today" chip);
  sample quantities illaatti file oda order quantities ("default" chip).
  Rendum maathalaam.
  Edhavadhu missing aa irundhaa popup varaadhu; entry screen la andha
  field red la kaattum.

STEP 4 - SAVED
  "Order PK/26-27/S/... is saved in Oracle" nu varum. Keezha "Order in
  Oracle": OC No, buyer, style, PO, dates, apram colour x size table
  (ovvoru colour ku ovvoru size la evvalavu pieces, total). Idhu save aana
  apram Oracle la irundhu thirumba padichadhu; approve pannadhum Oracle la
  irukuradhum same na "Verified in Oracle" green badge.
  "View the order in Oracle" - full screen la paakalaam, Print um pannalaam.
  "Not saved exactly as in the file" - Oracle ku pogaadha values oru table
  aa (chip mela mouse vecha kaaranam theriyum).
  "Technical details" - tables, record IDs, flowchart, "Open in Database"
  (IT / admin ku). "Start another order" - adutha file.

  CHECK & APPROVE screen la um adhe colour x size table "Order to be saved"
  nu varum; OC No "Assigned when saved". "Before you approve" table padichu
  "I've reviewed these items" tick panni approve pannunga.

MASTERS (buyer, style, colour, size, unit, merchandiser) - EPPADI MATCH AAGUM:
  - Same name Oracle la irundha adhe record use aagum.
  - Space, dot, comma, capital/small letter, "&" vs "AND", munnadi zero
    maathiram vithiyaasam na (udhaaranama Excel "Next Ltd." vs Oracle
    "NEXT LTD"), pudhu record create pannaama irukura record ae use aagum.
    Andha field la "is the existing buyer NEXT LTD" nu note varum.
  - 3 letters or kammi (S, XL, PCS) exact aa irundha mattum match.
  - Unmaiyaana pudhu name na pudhu master record create aagum. Similar name
    already irundha ("NAVY BLUES" vs "NAVY BLUE") approve ku munnadi note
    kaattum. Thappu na field la correct name type pannunga. Block pannaadhu.
  - Style numbers ah similar nu guess pannaadhu (ZK-2002 vs ZK-2003 rendu um
    vera vera styles).
  - Rendu existing records ku match aanaa ("NEXT LTD" and "NEXT, LTD"),
    exact name type pannanum nu sollum.

ENNA ENNA SAVE AAGUM:
  - Order header (ORDMAS), colour lines (ORDSTYLE), size quantities (ORDSIZE)
    + thevaiyaana masters.
  - Fabric (ORDFAB), yarn (ORDYARN), accessories (ORDACC): admin Setup ->
    Write mapping la verify panna apram dhaan save aagum. Adhuvarai
    "reference only - not saved" nu kaattum, check mattum aagum.
  - Save aanadhum POPPYS_APP.PP_IMPORT_LOG la receipt (yaaru, eppo, enna).

RULES (safety):
  - Ore file rendu thadava save aagaadhu ("already been committed").
  - Oracle la already irukura order reference ku thirumba save aagaadhu.
    Existing orders overwrite aagaadhu.
  - Ore file la 1-50 orders, order ku 1-100 lines, line ku 1-100 sizes.
  - Approve pannuradhuku munnadi edhaavadhu maathunaa, pazhaya preview
    cancel aagum; thirumba "Check & continue" pannanum (approve pannunadhu
    exact aa preview pannadhu dhaan nu guarantee).

PART 7A - PUDHU BUYER FORMAT (LAYOUT TEMPLATE)

PART 9. ASK AI SCREEN
--------------------------------------------------------------------------------

EPPADI KEKKANUM:
  Saadharana English la. Udhaaranam:
    How many orders for NEXT?
    Size wise quantity for order PK/26-27/S/9001
    Buyer wise order quantity this year
    Top 5 buyers by quantity
    Colour wise quantity for NEXT
    Orders by month
    Orders NEXT ZARA          (rendu buyers - "either" nu purinjukkum)
    Cancelled orders
  Order number, buyer name, colour ellame exact aa type panna better.

ANSWER LA ENNA IRUKKUM:
  - "Understood as": eppadi purinjikittadhu.
  - Table + chart (theva padumbodhu). "Download CSV".
  - Summary line (total, "All groups together").
  - Check strip: "6 of 6 checks passed" madhiri. 6 checks:
      1 Understand   - kelviya purinjikittadhu
      2 Build        - catalog la irundhu dhaan query build aachu
      3 Safety       - query padikka mattum; vera schema, DB link, maathura
                       command edhuvum illa (independent checker)
      4 Join check   - rows rendu thadava count aagaadhu nu check
      5 Execute      - read-only account la run aachu
      6 Totals       - breakdown ah total oda cross-check (groups add up)
    "How this was answered and checked" open panna ovvoru check um, exact
    read-only query um theriyum.
  - Confidence: high / medium / low. Low na carefully paarunga.
  - "Did you mean": rendu vidhama purinjikka mudinja, innoru answer button.
  - Tables flowchart: answer ku use aana tables. "+" linked tables kaattum.
    Table click panna preview; adhula column ah answer la add pannalaam, sariyaana
    join oda thirumba run aagum.
  - "Is this right?":
      "✓ Correct - remember it" -> adhe madhiri kelvi ku next time indha
      answer method use aagum (Setup -> Data dictionary -> Confirmed answers).
      "✗ Not right" -> record aagum.

UPLOAD PANNA FILES PATHI UM KEKKALAAM (Oracle off la irundhaalum).

ASK AI PANNAADHU:
  - Oracle la edhaiyum maathaadhu (POPPYS_RO account ku SELECT mattum).
  - GARMENT_DEMO thavira vera schema padikkaadhu.
  - Romba periya results ah limit pannum (first rows mattum, adhu sollum).
  - Local AI (Ollama) illama kooda odum (rules vechu). Ollama irundha konjam
    kashtamaana kelvigalaiyum purinjukkum.
